# Idiomas: português e inglês

Os textos do painel, mensagens de validação da API, ajuda dos comandos, status do terminal e mensagens de log do projeto ficam em `src/locales/pt-BR.json` e `src/locales/en-US.json`.

Não há tradução automática, inferência pelo conteúdo da mensagem, geração de chaves em execução ou serviço externo de tradução. Cada texto utiliza uma chave explícita do catálogo. As duas versões são mantidas manualmente.

## Escolher o idioma

No painel, use o seletor de idioma. A preferência fica salva neste navegador. As requisições enviam `X-Eatventure-Locale`, permitindo que navegadores diferentes recebam as mensagens da API no seu próprio idioma.

No terminal, informe `--locale pt-BR` ou `--locale en-US` nos comandos de entrada do bot, do painel e da IA. As formas curtas `pt` e `en` também são aceitas. Por exemplo:

```powershell
python src/main.py --locale en-US --device SERIAL
python src/web.py --locale pt-BR
python IA/train_ai.py --locale en-US
```

Também é possível definir o padrão para o processo e seus filhos:

```powershell
$env:EATVENTURE_LOCALE = "en-US"
```

Sem uma escolha, o padrão é `pt-BR`. Um idioma desconhecido usa esse mesmo padrão.

## Adicionar textos

Use chaves curtas em inglês e `snake_case`, descrevendo o propósito do texto: `jpeg_quality`, `wait_after_action`, `check_for_new_templates` ou `full_screen_model_warning`. Não transforme frases inteiras em nomes de chave. O validador limita as chaves de texto a 40 caracteres.

Adicione a mesma chave nos dois arquivos, usando os mesmos parâmetros:

```json
{
  "web": {
    "device_count": "{count} dispositivos"
  }
}
```

```json
{
  "web": {
    "device_count": "{count} devices"
  }
}
```

No JavaScript, use `t("web.device_count", { count })`. No Python, use `t("web.device_count", count=total)`. Para textos estáticos do HTML, use `data-i18n="web.devices"` e `{{web.devices}}`. Atributos possuem marcadores próprios, como `data-i18n-placeholder` e `data-i18n-aria-label`.

Mensagens Python com formato numérico mantêm seus especificadores, como `{seconds:.1f}`. Logs com argumentos separados mantêm os especificadores de logging, como `%s` e `%d`.

## Limites da apresentação

Estados, ações, nomes de configurações, categorias de templates, caminhos, modelos, nomes escolhidos pelo usuário e protocolos mantêm seus valores internos. Rótulos conhecidos são traduzidos somente ao exibir os dados. Categorias e identificadores externos desconhecidos são mostrados como recebidos.

Os logs próprios dos workers fornecem versões em português e inglês, produzidas pelas mesmas chaves JSON. O painel pode trocar o idioma das linhas retidas e do download sem reiniciar o bot. Linhas antigas sem esses metadados e saídas livres de ADB, scrcpy, bibliotecas, sistema operacional e tracebacks são preservadas como recebidas.

As marcações desenhadas pelo worker nos frames usam o idioma do processo, definido no terminal; o seletor do navegador não reescreve os pixels dos frames.

## Verificação estática

```powershell
python tools/sync_locale_catalog.py --check
node --check src/dashboard/static/app.js
```

Apesar do nome histórico, `sync_locale_catalog.py` somente valida os arquivos. Ele verifica a igualdade de chaves e parâmetros, referências Python e JavaScript, sintaxe Python e marcadores do HTML. Não gera textos nem inicia o projeto.
